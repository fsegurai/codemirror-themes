# What's New in 1.2.2

Released 2024-06-11. Housekeeping for the root package and the demo pipeline.

## Changes in 1.2.2

| Area | Change |
|------|--------|
| Root package | `package.json` gained metadata (version, homepage, license, repository). The `example` scripts were renamed to `npm start` and `npm run build`. |
| Demo | Updated demo pipeline setup. |

## Also new since 1.1.1

These docs follow 1.1.1. Release 1.2.0 (2024-05-21) added:

| Item | Details |
|------|---------|
| Bundle package | `@fsegurai/codemirror-theme-bundle` 6.0.0 re-exports the 20 combined theme extensions. See [Bundle](../api/bundle.md). |
| Selection styles | Improved selection colors in Andromeda, Basic, Forest, Gruvbox, Material, Nord and Solarized; those packages moved to 6.0.3 or 6.0.4. |

The full entry is in the [changelog](https://github.com/fsegurai/codemirror-themes/blob/main/CHANGELOG.md).
