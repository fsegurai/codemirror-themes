# What's New in 1.3.2

Released 2024-10-23. A maintenance release: dependency updates and a README fix. Theme sources are unchanged since
1.2.2.

## Changes in 1.3.2

| Area | Change |
|------|--------|
| README | The usage example now imports from the scoped package `@fsegurai/codemirror-theme-basic-light`. |
| Packages | Every theme package and the bundle published as 6.0.5; the bundle depends on `^6.0.5` of each theme. |
| Dependencies | `@codemirror/lang-markdown` 6.3.0, `@codemirror/language` 6.10.3, `@codemirror/legacy-modes` 6.4.1, `@lezer/markdown` 1.3.1. |
| Dev dependencies | `@codemirror/buildhelper` 1.0.2, `rollup` 4.24.0, `typescript` 5.6.3 and other updates. |

## Also new since 1.2.2

These docs follow 1.2.2. Release 1.3.1 (2024-10-21) added a Dependabot configuration, fixed the demo deployment and
npm publish pipelines, and updated `@codemirror/language` to 6.10.2.

The full entry is in the [changelog](https://github.com/fsegurai/codemirror-themes/blob/main/CHANGELOG.md).
