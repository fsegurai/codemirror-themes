# Examples

| Example | Shows |
|---------|-------|
| [Basic Editor](basic-editor.md) | One theme with a language extension. |
| [Theme Picker](theme-picker.md) | A `<select>` that switches between bundle themes. |
| [Merge View](merge-view.md) | A side-by-side diff with themed revert buttons that follow the picker. |

All examples are browser code and assume a bundler such as Vite. The
[demo source](https://github.com/fsegurai/codemirror-themes/tree/main/demo) contains a full working playground for the latest release.
