# What Is New in 6.32.0

## Highlights

- **New package `@fsegurai/codemirror-theme-core` (`6.0.0`).** The theme builder is public: `defineTheme`,
  `ThemeDefinition`, `UiPalette` and the syntax role types, so applications can define a theme with the same complete
  structure as the published ones. See [Core Package](../api/core.md).
- **`cssVariableTheme(options?)`.** One theme whose UI and syntax colors are CSS custom properties with fallbacks
  (`var(--cm-background, #ffffff)`, `var(--cm-syntax-keyword, #cf222e)`, …), so one extension follows any CSS theme.
  Options: `prefix`, `dark`, `variables` and `fallbacks`; `cssVariableNames()` lists every variable it reads. See
  [CSS Variable Theme](../api/css-variable-theme.md) and the new
  [CSS variables playground sample](../../playground/css-variables/).
- **Bundle re-exports the core API.** `@fsegurai/codemirror-theme-bundle` also exports `defineTheme`,
  `cssVariableTheme`, `cssVariableNames` and the theme types.
- **One shared copy.** Every theme package depends on the core instead of carrying its own copy of the builder, so
  installing several themes installs the builder once.

Theme exports and generated styles are unchanged: the output snapshots of every theme are identical to 6.31.0. Every
package still exports `<theme>`, `<theme>MergeStyles` and `applyMergeRevertStyles`.

Every theme moves to its next minor version because it has a new runtime dependency on
`@fsegurai/codemirror-theme-core@6.0.0` (exact pin). The bundle pins every theme and the core to these exact
versions.

## Upgrade notes

| Change | What to do |
|--------|------------|
| Themes depend on the core | Nothing: your package manager installs it with the theme. Lockfiles gain one package. |
| You copied `theme-core.ts` to build your own theme | Import `defineTheme` and the types from `@fsegurai/codemirror-theme-core` instead (see [Creating a Custom Theme](../guides/custom-theme.md)). |
| Import maps or CDN setups (no bundler) | Add an entry for `@fsegurai/codemirror-theme-core`: the theme builds import it. The [playground import map](../../playground/playground.json) shows the exact pins. |
| You want one theme for light and dark CSS themes | Use `cssVariableTheme` and set `--cm-*` variables; reconfigure only the `dark` flag when the page mode changes. |

## Publish order

The theme and bundle builds import the core instead of inlining it, so a theme published before the core cannot be
installed. Publish `@fsegurai/codemirror-theme-core` first, then the 33 theme packages, then the bundle.

The full list of changes is in the
[changelog](https://github.com/fsegurai/codemirror-themes/blob/main/CHANGELOG.md).
