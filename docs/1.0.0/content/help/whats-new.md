# What's New in 1.0.0

Released 2024-04-29. The first official release: **20 themes for CodeMirror 6**, each published as its own package.

## New

| Item | Details |
|------|---------|
| Themes | Abcdef, Abyss, Android Studio, Andromeda, Basic Dark, Basic Light, Forest, GitHub Dark, GitHub Light, Gruvbox Dark, Gruvbox Light, Material Dark, Material Light, Monokai, Nord, Solarized Dark, Solarized Light, Tokyo Night Day, Tokyo Night Storm and Volcano. See the [catalog](../themes/README.md). |
| Packages | `@fsegurai/codemirror-theme-<name>`, version 6.0.1, ESM and CommonJS builds. |
| Exports | `<theme>`, `<theme>Theme` and `<theme>HighlightStyle` per package. See the [API reference](../api/README.md). |
| Example page | `example/` renders a Markdown document with a theme selector (`npm run example`). |

## Not in this release

- No bundle package; `@fsegurai/codemirror-theme-bundle` arrived in 1.2.0.
- No hosted demo; the demo site arrived in 1.1.0.

The full entry is in the [changelog](https://github.com/fsegurai/codemirror-themes/blob/main/CHANGELOG.md).
