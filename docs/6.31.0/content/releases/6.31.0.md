# What Is New in 6.31.0

## Highlights

- **WCAG AA in every theme.** Text reaches 4.5:1 on the background, the active line and the selection; the cursor,
  focus ring, matching bracket and current search match reach 3:1. See [Accessibility](../accessibility/README.md).
- **Four new themes:** [Dracula](../themes/dracula.md), [One Dark](../themes/one-dark.md),
  [Catppuccin Latte](../themes/catppuccin-latte.md) and [Rosé Pine Dawn](../themes/rose-pine-dawn.md). The catalog now
  has 33 themes.
- **One shared structure.** Every theme is built from the same internal `ThemeDefinition` (a complete UI palette and
  syntax roles), so all themes style the same selectors and every Lezer tag. Themes now differ only by their colors.
- **Visible keyboard focus.** A 2px focus ring on every theme, which also survives Windows High Contrast
  (forced colors).
- **Scoped merge-view styles.** The `del`/`ins` rules of merge views only apply inside `.cm-*` elements, so they no
  longer restyle `<del>` and `<ins>` elsewhere on the page.
- **Download badges.** The READMEs show npm total downloads per package.

The public API is unchanged: every package still exports `<theme>`, `<theme>MergeStyles` and
`applyMergeRevertStyles` with the same names and types.

## Upgrade notes

| Change | What to do |
|--------|------------|
| Colors changed in most themes | Nothing, unless you test screenshots or copied theme colors into your own CSS. Check the table below. |
| `oneDark` now exists in this project too | `@codemirror/theme-one-dark` exports the same name. Alias one of them: `import { oneDark as fsOneDark } from '@fsegurai/codemirror-theme-one-dark'`. |
| New focus ring | If you added your own `.cm-focused` outline, remove it or override the theme with `Prec.highest` (see [Overriding Theme Styles](../guides/overriding-styles.md)). |
| Merge-view `del` rules scoped | If you relied on the theme styling plain `<del>` elements outside the editor, style them yourself. |
| UI parts and tags styled for the first time | Buttons, text fields, the go-to-line panel, completion info, lint tooltips and markers, merge spacers, snippet fields, special and trailing whitespace characters, placeholders and seven Lezer base tags (`literal`, `docString`, `definitionOperator`, `typeOperator`, `controlOperator`, `content`, `documentMeta`) now use theme colors. |
| Cobalt2 | Rules for `.cm-hoverHighlight`, `.cm-wordHighlight` and `.cm-indentGuide` were dropped; they are not CodeMirror classes. |

## GitHub Light and issue #140

Issue [#140](https://github.com/fsegurai/codemirror-themes/issues/140) reported GitHub Light keywords (`#d73a49`) and
numbers (`#e36209`) below 4.5:1 and suggested the Primer colors `#cf222e` and `#953800`. Numbers now use `#953800`.
Keywords use `#c10722`, a slightly darker red, because `#cf222e` still fell below 4.5:1 (3.85:1) on the light-blue
selection. The same
check was then applied to every theme.
