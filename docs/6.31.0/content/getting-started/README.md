# Getting Started

Two steps take you from zero to a themed editor.

1. [Installation](installation.md) - choose a single theme package or the bundle.
2. [Quick Start](quick-start.md) - add the theme extension to an `EditorView`.

## Requirements

| Requirement | Version |
|-------------|---------|
| `@codemirror/view` | `^6.0.0` (peer) |
| `@codemirror/state` | `^6.0.0` (peer) |
| `@codemirror/language` | `^6.0.0` (peer) |
| `@lezer/highlight` | `^1.0.0` (peer) |

The `codemirror` meta-package installs all four peers, so `npm install codemirror` is usually enough.
