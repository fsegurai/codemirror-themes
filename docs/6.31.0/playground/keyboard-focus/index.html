Keyboard only

  1. Press Tab until the editor is focused: the theme draws a 2px ring around it.
  2. Type, move with the arrow keys, select with Shift + arrows. Tab indents here.
  3. To leave the editor, press Esc and then Tab (within two seconds), or toggle tab focus mode with Ctrl + M (Shift + Alt + M on macOS).
  4. Shift + Tab moves focus back the same way.

What the theme does

The focus ring is a box-shadow, so it follows the theme colors and is never clipped by the editor border. In forced-colors mode (for example Windows Contrast themes) browsers remove box-shadows; the themes also set outline: 2px solid transparent on .cm-focused, which forced-colors mode repaints in a system color, so a ring stays visible. Never reset that outline with outline: none in your own CSS.
